# Changelog

This project follows [Semantic Versioning](VERSIONING.md).

## 1.0.0 - 2026-08-21

- Stabilized the public contracts for Mermaid diagrams, portable Modelica projects, and portable mind maps.
- Added reproducible release gates, cross-platform CI, deterministic inventories, security guidance, and submission dossiers.

## 0.3.0 - 2026-08-21

- Reduced the collection to three open-format, vendor-neutral plugins.
- Added `modelica-projects` with deterministic package generation and portable static checks.
- Removed proprietary notebook and proprietary Modelica runtime integrations.
- Generalized the diagram and mind-map plugins around portable formats.

Earlier releases were withdrawn because their scope and distribution boundaries no longer match the project.
