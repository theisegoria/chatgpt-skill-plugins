# Support

For reproducible bugs, compatibility reports, or feature requests, open an issue in the [chatgpt-skill-plugins support tracker](https://github.com/theisegoria/chatgpt-skill-plugins/issues).

Include:

- the plugin name and version;
- the ChatGPT or Codex version and operating system;
- the relevant desktop application and version, if runtime validation was attempted;
- the command or prompt used;
- the smallest non-sensitive input that reproduces the problem;
- the complete error message; and
- whether the portable/static output succeeded.

Do not attach confidential source files, credentials, proprietary models, or private generated artifacts to a public issue.

Support is provided on a best-effort basis. Theisegoria does not operate a hosted service for these plugins and cannot administer third-party application accounts, licenses, permissions, or platform access.
